# HelpDesk

Sistema interno de gerenciamento de chamados desenvolvido em **Python** como projeto prático de Back-End.

O projeto está sendo construído de forma incremental, com foco em regras de negócio, programação orientada a objetos, organização de código e separação de responsabilidades.

> 📚 **Projeto de aprendizado em desenvolvimento**
>
> Desenvolvido a partir de casos práticos e ciclos de implementação, revisão de código e refatoração.
